# White Noise Generator

A simple, elegant web application for generating white, pink, and brown noise to help with focus, relaxation, and sleep.

## Features

- **Three Noise Types**
  - White Noise: Full frequency spectrum, ideal for masking distractions
  - Pink Noise: Lower frequencies emphasized, often preferred for sleep
  - Brown Noise: Even deeper bass frequencies, very calming

- **Volume Control**: Adjustable volume slider for precise control

- **Clean Interface**: Minimal, distraction-free dark theme design

- **Mobile Responsive**: Works seamlessly on desktop, tablet, and mobile devices

- **No Dependencies**: Built with vanilla JavaScript, HTML, and CSS

## Usage

1. Select a noise type (White, Pink, or Brown)
2. Adjust the volume slider to your preference
3. Click "Play" to start the noise
4. Click "Pause" to stop

## Technical Details

This app uses the Web Audio API to generate noise in real-time:

- **White Noise**: Generated by creating random values for each audio sample
- **Pink Noise**: Filtered white noise using Paul Kellet's algorithm with weighted frequency bands
- **Brown Noise**: Created using a random walk algorithm with integration of white noise

### Browser Compatibility

Works in all modern browsers that support the Web Audio API:
- Chrome/Edge 35+
- Firefox 25+
- Safari 14.1+
- Opera 22+

## Local Development

Simply open `index.html` in a modern web browser. No build step or server required.

```bash

git clone https://github.com/yourusername/white-noise.git

# Open in browser
open index.html
```

## GitHub Pages Deployment

This app is designed to be deployed on GitHub Pages:

1. Push your code to a GitHub repository
2. Go to repository Settings > Pages
3. Select source: `main` or `master` branch, root directory
4. Your app will be available at: `https://yourusername.github.io/white-noise`
